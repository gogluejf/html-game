# Techniques

Working recipes for browser/CDP operations the skills don't cover out of the box.
One file per technique, short and copy-pasteable. Add a new `<topic>.md` here
whenever you solve a fiddly interaction problem — future runs should reuse it,
not re-discover it from old session logs.

## Index

- [upload-file.md](upload-file.md) — Upload a local image/file into ChatGPT's composer via CDP (no drag-drop, no UI clicking).
