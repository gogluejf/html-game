## Screen-space decay (linear, per fixed step)

| value | constant | file:line | note |
|---|---|---|---|
| vignette full-fade time = 0.5s | `VIGNETTE_DECAY = 1 / 0.5` (= 2.0 /s) | js/effects.js:27 | `vignette -= VIGNETTE_DECAY * dt`, clamped at 0 (js/effects.js:178) |
| screenFlash full-fade time = 0.15s | `FLASH_DECAY = 1 / 0.15` (= 6.666…/s) | js/effects.js:28 | `screenFlash -= FLASH_DECAY * dt`, clamped at 0 (js/effects.js:181) |

Fixed-dt behavior (from Effects.update(dt), js/effects.js:174-184):
- vignette: set to 1 by heroDamaged() → after update(0.25) == 0.5; after further update(0.3) == 0 (asserted in js/test/effects.test.js:24-28)
- screenFlash: set to 1 by bigExplosion() → after update(0.075) ≈ 0.5 (±0.02); after further update(0.1) == 0 (asserted in js/test/effects.test.js:39-43)
- both kick via max(): `this.vignette = Math.max(this.vignette, min(1, strength))` (js/effects.js:52), same for screenFlash (js/effects.js:62)
- reset() zeroes both (js/effects.js:255-258)
